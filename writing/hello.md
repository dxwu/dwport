This site is a folder of HTML files, one stylesheet, one script, and a handful of JSON files. There is no build step. GitHub Pages serves it as-is.

## Adding work

- **Galleries** (ceramics, sculpture, painting, film): drop the image into `images/<section>/`, then add an entry to `data/<section>.json`.
- **Writing**: write a markdown file in `writing/`, then add an entry to `data/writing.json`.
- **CS projects**, **piano**, **books**: edit the matching JSON in `data/`.

That's the whole workflow. The README has details.
